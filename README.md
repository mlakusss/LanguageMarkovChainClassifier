# Определение языка текста с помощью марковских цепей (back-off, без сглаживания)

[![.NET](https://img.shields.io/badge/.NET-8.0-blue)](https://dotnet.microsoft.com/)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

Приложение с графическим интерфейсом (Windows Forms) для определения языка текста. Использует марковскую цепь порядка 6 с back-off (без аддитивного сглаживания). Обучено на датасете WiLI‑2018 (235 языков, 117 500 документов). Достигает 100% точности на одноязычных текстах и корректно обрабатывает иноязычные цитаты.

## Возможности

- **Марковская цепь порядка 6** с back-off (усечение контекста) – без сглаживания
- **Взвешивание цитат** – текст внутри кавычек («...», "...", “...”) имеет пониженный вес (0.05), что снижает влияние иноязычных вставок
- **Мягкая алфавитная фильтрация** – исключаются языки, чей алфавит не пересекается с буквами текста
- **Быстрое обучение** – ~35 секунд на 117 500 документах (235 языков)
- **Простой графический интерфейс** – выбор папки с данными, запуск обучения, выбор тестового файла и вывод результата в лог
- **Юнит-тесты** – 10 тестов, проверяющих определение основных языков, обработку цитат и смешанных текстов


## Требования

- Windows (приложение использует Windows Forms)
- .NET 8.0 Runtime (или SDK для разработки)
- Для обучения: датасет WiLI‑2018 или папка с подпапками языков (в каждой подпапке – текстовые файлы на соответствующем языке)

## Использование
Использование
1. Обучение модели:

Нажмите «Обзор...» рядом с «Папка с данными» и выберите папку, содержащую файлы x_train.txt и y_train.txt (формат WiLI) или папку с подпапками языков.

Нажмите «Обучить». Дождитесь завершения – в логе появится сообщение «Обучение завершено».

2. Классификация текста:

Нажмите «Обзор...» рядом с «Тестовый файл» и выберите текстовый файл (.txt).

Нажмите «Классифицировать». Результат (язык, уверенность, топ‑5 кандидатов) появится в логе.

## Параметры классификатора (по умолчанию)
maxOrder = 6 – порядок марковской цепи (длина контекста)

quoteWeight = 0.05 – вес для фрагментов в кавычках

fallbackProb = 1e-9 – вероятность для полностью неизвестных переходов

Вы можете изменить эти параметры в конструкторе Form1.cs при создании экземпляра классификатора.

## Тестирование

В Visual Studio: меню Тест → Запустить все тесты

Или через консоль: dotnet test

## Структура проекта
Form1.cs – главная форма приложения (загрузка данных, интерфейс)

MarkovChainBackoffClassifier.cs – реализация классификатора (марковская цепь с back-off)

LanguageDocument.cs – модель документа (текст + метка языка)

kursachm.Tests/ – юнит-тесты

## Датасет WiLI‑2018
WiLI (Wikipedia Language Identification) – датасет, содержащий тексты из Википедии на 235 языках. Файлы:

x_train.txt – тексты (по одному на строку)

y_train.txt – метки языков (коды, например eng, rus, fra)

Если у вас нет датасета, вы можете использовать свою структуру папок: создайте корневую папку, внутри неё – подпапки с названиями языков, а в каждой подпапке – текстовые файлы на этом языке.
